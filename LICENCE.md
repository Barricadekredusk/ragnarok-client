## 🧩 About

**Ragnarok Online Client** is a comprehensive companion client for Ragnarok Online featuring a custom launcher, overlay HUD, skill timers, inventory helper, chat macros, and a stat calculator.

Based on popular tools like **ROClient**, **OpenKore**, and **RagOverlay**.

---

## ✨ Features

### 🎮 Core Client
- Custom Launcher — start the game with modded settings
- Overlay HUD — show HP, SP, EXP, and zeny on screen
- Skill Timers — track cooldowns for active skills
- Inventory Helper — quick sort, filter, and search items
- Chat Macros — bind common phrases to hotkeys

### 🎨 Interface & Customization
- Custom UI Skins — swap window frames and button styles
- Damage Fonts — change floating damage text style
- Minimap Enhancements — show NPCs, monsters, and portals
- Solid Wave Trail — improved cursor trail visibility

### 🏋️ Utility & Training
- Stat Calculator — plan builds before resetting
- Monster Database — view drops, elemental weakness, and spawn maps
- Quest Tracker — follow quest chains on the overlay
- Auto-Pot Helper — reminder when HP or SP is low
